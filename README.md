# Systeme de Gestion Hoteliere en C++

## Description

Ce projet est une application console developpee en C++ qui permet de gerer les principales operations d'un hotel.  
L'application offre une interface simple, coloree et organisee permettant de gerer les clients, les chambres, les reservations ainsi que les statistiques de l'hotel.

Ce projet a ete realise dans un but academique afin de pratiquer les notions fondamentales de la programmation en C++, notamment les structures, les vecteurs, les fonctions, les conditions, les boucles et la gestion des donnees en memoire.

---

## Fonctionnalites

### Gestion des clients

- Ajouter un nouveau client
- Afficher la liste des clients
- Rechercher un client par nom ou prenom
- Modifier les informations d'un client
- Supprimer un client

### Gestion des chambres

- Afficher toutes les chambres
- Afficher uniquement les chambres disponibles
- Ajouter une nouvelle chambre
- Modifier le prix d'une chambre
- Voir le statut d'une chambre : libre ou occupee

### Gestion des reservations

- Creer une nouvelle reservation
- Associer une reservation a un client
- Associer une reservation a une chambre disponible
- Afficher toutes les reservations actives
- Annuler une reservation
- Liberer automatiquement la chambre apres annulation
- Rechercher les reservations d'un client

### Tableau de bord

- Afficher le nombre total de chambres
- Afficher les chambres libres
- Afficher les chambres occupees
- Afficher le nombre total de clients
- Afficher le nombre de reservations actives
- Calculer un revenu estime
- Afficher le taux d'occupation de l'hotel
